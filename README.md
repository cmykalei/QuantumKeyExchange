# Quantum Key Exchange
Implementing the QKE algorithm with the goal of agreeing on a shared secret key.

## Project 🌳
```
.
├── README.md
├── main.py
├── qke_test.py
├── qke.py
├── qubit_test.py
├── qubit.py
├── xorcipher_test.py
├── xorcipher.py
├── logs/
    ├── report.md
    ├── demo_qke.txt
    ├── test_qke.txt
    ├── test_qubit.txt
    └── test_xorcipher.txt
```

### Usage
- Go to [logs/demo_qke.txt](logs/demo_qke.txt) to see the output of the program.
- Go to [logs/report.md](logs/report.md) for the final report.

## Commands
1. To run the key exchange demo use `python main.py`.
2. To run the tests use `python qke_test.py`, `python qubit_test.py`, or `python xorcipher_test.py`.
